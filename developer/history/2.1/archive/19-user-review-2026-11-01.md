## Decisions I made (to confirm)
1. **Back goes to the page the user came from.** The address of the previous page is read from the request when the page or form is first opened, kept only if it is on this site, and used for the Back button, so a form that is re-shown after a validation error still goes back to the right page. If there is none, Back goes to Manage Elections (lists and forms) or to the election overview (forms of one election). It is a link, so nothing is saved.
2. **Which screens get the standard.** Edit forms as a full page: Edit and Create Election, Add and Edit Position, Add Candidate, the candidate statement, the Results page form. View pages: the election overview and the Positions, Candidates, Results and Audit log pages. Dialogs that open in a popup (Duplicate, Delete, Activate, Deactivate, Withdraw) keep their own buttons, because a popup closes itself.
3. **Breadcrumb trails.** `Manage Elections`, then `<election name>` (the overview), then the page: `Manage Elections › Beekeeper Committee 2027 › Positions`. Forms of a position or candidate go through the election and the list page.
4. **Submit (The maintainer, 2026-11-01: use only the word Submit on every edit form, never Save).** The primary button is **Submit** on Edit and Create Election (already), Add and Edit Position (was Create / Edit Position), Add Candidate (was Add Candidate), the candidate statement (was Save) and the Results page form (was Save). Confirmation dialogs keep the verb of what they do (Delete, Duplicate, Activate, Deactivate, Withdraw, Accept, Nominate) because they are not edit forms. The inline Save of the SearchKit lists is SearchKit's own and is left as it is.
5. **Edit Election when the election has already run.** The form refuses to open then ("cannot be edited once it has been run"). The button stays in first place but is shown disabled with that reason, so the row does not change shape and the reason is visible. It was hidden before.
6. **Fingerprint wording.** The text says what it is and what to do with it, shows all 64 characters in a fixed width font that wraps, and the copy button gives a short "Copied" confirmation and works without the clipboard permission (falls back to selecting the text).
7. **Audit log labels.** A fixed list gives each action a label (Election changed, Election created, Election deleted, the same for Position and Candidate, Results generated, Vote removed, Votes anonymised, Write-ins summary). An action that is not in the list gets its name turned into words, so a new kind of entry never shows a code. The same labels are used in the Audit log page.
