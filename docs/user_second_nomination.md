# How to second a nomination

Each election has a **Required nominations** setting, which is the number of people who must nominate a person for a position before that person becomes an eligible candidate. Each additional nomination for the same person and position is called a **second**.

If a nomination still needs more people to second it, it is shown with a **Second Nomination** button while nominations are open.

1. Go to **Elections**.
2. Open the election (select **Nominate** on its card, or **View Election**), and find **Nominations for** the position.
3. Find the nomination that needs a second, and select **Second Nomination**.
4. The **Nominate in** page opens with the **Position** and **Nominee** already chosen. Enter the **Reason for the nomination**, then select **Nominate**.

Once a nomination has received the required number of nominations, the nominee becomes an eligible candidate and can [accept the nomination](user_accept_nomination.md). No further seconds are needed or accepted after that point.

If **Required nominations** for the election is set to 1, then a single nomination is enough to make the nominee an eligible candidate, and seconding is not required.
