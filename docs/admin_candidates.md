# Candidates

**Candidates** for an election (open it from the election's [overview](admin_election_overview.md)) lists everyone nominated, one row for each nomination. The page has a breadcrumb (**Manage Elections** > the election's name > **Candidates**) and the buttons **Back**, **Back to Manage Elections** and **Add Candidate**. Use the filters above the list (**Name**, **Position**, **Eligible** and **Accepted**, with **Clear filters**) to find a person. The columns are:

- **Name** (select the name to see their candidate page), the **Position**, and how many people nominated them (**Nominators**).
- **Eligible**: they have enough nominations to be a candidate (see **Required nominations** in [How to add a new election](admin_create_election.md)).
- **Accepted**: the nominee has accepted, so they appear on the ballot.
- **Status**: **Nominee** (not accepted yet), **Candidate** (accepted), **Declined** (said no before accepting) or **Withdrawn** (pulled out after accepting).
- The candidate's **Statement** and **Statement link**.

Select a statement, a link or a Yes/No value to change it in place, then confirm with the tick. Select **Edit Statement** on a row to open the full form (**Statement** and **Statement link**, then **Submit**).

- Who is standing (**Eligible** and **Accepted**) can be changed until **voting starts**. After that it is fixed, so the ballot cannot change while people are voting.
- Statements and links can be corrected until **voting ends**.

When there is nobody to show the list says so and suggests clearing the filters, adding a candidate or opening nominations.

## Add Candidate

Use **Add Candidate** when nominations are made outside the website, for example by a board. Choose the **Position** and the **Candidate** (the person), optionally enter their **Statement**, and tick **Mark as accepted** if they have already agreed to stand, so they appear on the ballot (otherwise they are asked to accept). Select **Submit**; the message "Candidate added." is shown. The person must belong to one of the election's groups; add them to a group first if they do not. Candidates can be added until voting starts. If the election has no positions yet, the page says so and links to add a position first.
