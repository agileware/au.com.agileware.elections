# How to reorder positions

The order in which positions are listed for nomination, voting and results can be changed while the election is inactive, or before the election is active.

To reorder positions, you need to have CiviCRM admin access and follow these steps:

1. Go to **Elections**.
2. Go to **Positions** for the election you want to reorder.
3. Drag and drop rows in the positions table into the order you want. The new order is saved automatically as you drop each row.

The **Order** field on the [Add Position](admin_add_position.md) and [Edit Position](admin_edit_position.md) forms can also be used to set a position's order directly.
