# How to reorder positions

The order in which positions are listed for nomination, voting and results can be changed while the election is inactive, or before the election is active.

To reorder positions, you need to have CiviCRM admin access and follow these steps:

1. Go to **Elections** and click **Positions** for the election you want to reorder.
2. Drag the handle at the start of a row to where you want the position. The other positions move to make room and the new order is saved as soon as you drop the row.

Positions can also be renamed, or have their seats or description changed, by selecting the value in the list. A position can be **duplicated** (the copy goes to the end of the list) or **deleted** from the buttons on its row. Positions can only be changed before the election starts.

The **Order** field on the [Add Position](admin_add_position.md) and [Edit Position](admin_edit_position.md) forms can also be used to set a position's order directly.
